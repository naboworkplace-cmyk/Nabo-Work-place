FREE GITHUB PAGES PUBLISHING
----------------------------
1. Go to GitHub and sign in.
2. Create a new public repository, e.g. nabo-work-place.
3. Upload ALL contents of this folder to the repository root.
4. Open repository Settings.
5. Open Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Branch: main, Folder: / (root), then Save.
8. Wait about 1-3 minutes and GitHub will show the live site URL.

The website is static and requires no paid hosting, backend, npm, or build command.
